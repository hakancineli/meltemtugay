# Meltem Tugay Psikolog Web Sitesi

Meltem Tugay psikoloji web sitesi projesi.

## Özellikler

- Psikolojik danışmanlık hizmetleri
- Online randevu sistemi
- Psikolojik testler
- Blog yazıları
- Hizmetler hakkında detaylı bilgiler

## Kurulum

Proje yerel olarak çalıştırmak için:

```bash
# Proje dizinine gidin
cd meltemtugay

# HTTP sunucusunu başlatın
python3 -m http.server 8000
```

Tarayıcınızda `http://localhost:8000` adresini açarak siteyi görüntüleyebilirsiniz.

## Dağıtım

Proje Vercel üzerinde statik site olarak dağıtılır.
